Welcome to MyLastArch

MyLastArch 2026.11.01 combines the flexibility of Arch Linux with a polished KDE Plasma desktop and practical defaults for everyday use.

Running the live session? Connect to the internet, explore the desktop, then double-click Install MY LAST ARCH on the desktop when you are ready. Your disks are not changed until you confirm the installation choices.

Install MyLastArch

  • Connect to Wi-Fi or Ethernet first.
  • Open the installer from the desktop.
  • Review the summary carefully before installation begins.
  • The default computer name is mylastarch.

Hardware Support

The installer automatically configures detected graphics, virtual-machine tools, and compatible Broadcom wireless hardware.

Show recommendations

mylastarch-hwtool --recommended

Check installed packages

mylastarch-hwtool --check

Install or repair recommendations

sudo mylastarch-hwtool --install-recommended

Tip: Run the install/repair command on the installed system, not the temporary live session.

Getting Started

  • Use Arch Update in the system tray for updates.
  • Browse Windows network shares in Dolphin under Network.
  • Manage printers from the Plasma system tray or System Settings.
  • Use Ark for archives and Gwenview for viewing and resizing images.
  • Change wallpapers with Variety or the desktop context menu.

Safe Arch Updates

MyLastArch is a rolling-release system. Always perform a complete upgrade rather than a partial upgrade.

sudo pacman -Syu

Avoid running pacman -Sy by itself. Arch Update also checks Arch news and helps with post-update tasks.

System Information
